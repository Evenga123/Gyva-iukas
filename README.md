# Rožinė gyvatėlė

Naršyklėje žaidžiamas gyvačiuko žaidimas su rožine gyvate, rodyklių valdymu ir 3 gyvybėmis.

## Paleidimas

```bash
npm install
npm run dev
```

Tada atidarykite parodytą vietinį adresą naršyklėje.

## Vercel

Projektas paruoštas deploy per Vercel. Vercel gali naudoti standartinį `npm run build` ir publikuoti `dist` aplanką.
